# Dunk Shot (MSX) — a commented disassembly

*(También disponible [en castellano](README.es.md).)*

A commented disassembly of **Dunk Shot** (HAL Laboratory, 1986), a 32 KB
cartridge for the **MSX**: no mapper, in pages 1 and 2.

**The website**: https://antxiko.github.io/DunkShot-disassembly/

| | |
|---|---|
| explained | 100% (20,642 bytes of code, 12,126 of data) |
| commented | 43.2% of the instructions |
| routines | 1,289, none below 10% |
| reassembly | the ROM, byte for byte |
| pictures | drawn from the ROM; six screens checked against openMSX, 0 differences |

## What is here

- The listing (`src/dunkshot.asm`), generated from the binary and the notes,
  which reassembles the exact ROM.
- The whole 56-column court in its three colours, the title, the menus, the
  team card and the match, built from the cartridge's tables.
- The players: 160 poses of four sprites and 32 skin-and-hair looks.
- How it works: the 32-column window, the flickering sprite rotation, the
  computer teams generated by level, the tape as a BSAVE, the plays, the four
  compressors and the sound engine.

## How to reproduce it

You need Python 3, GNU make, [Pasmo](https://pasmo.speccy.org/) and **your own
image of the cartridge** as `dunkshot.rom` at the root:

```
sha256  a1891e038566596a9f67067b8ea4694709aa9fee93c8ac0379360b30ea3abe62
make
```

The details are in [Getting started](docs/GETTING-STARTED.md). `make parche`
builds the [MSX2 patch](docs/THE-MSX2-PATCH.md), which removes most of the
flicker on an MSX2 and still plays on an MSX1; it has its own repository,
[DunkShot-MSX2-Patch](https://github.com/antxiko/DunkShot-MSX2-Patch).
